\# Employee Management System



A full-stack Employee Management System built using React.js, Spring Boot, Spring Data JPA, and MySQL.



The application allows users to manage employee information through a React frontend connected to a Spring Boot REST API.



\## Features



\- View all employees

\- Add new employees

\- Edit employee details

\- Delete employees

\- Search employees

\- Filter employees by department

\- Department analytics

\- Form validation

\- Backend validation

\- Exception handling

\- RESTful APIs

\- MySQL database integration

\- React and Spring Boot integration
